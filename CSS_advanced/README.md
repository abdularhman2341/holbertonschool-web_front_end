# CSS Advanced

This project focuses on advanced CSS concepts and styling techniques.

## Learning Objectives

By the end of this project, I should be able to explain:

* Selectors, properties, and values
* The difference between block and inline styling
* CSS resets and browser consistency
* CSS variables
* Inline, embedded, and external CSS
* Grid systems using floats
* Icon webfonts and SVG icons
* Pseudo-classes and pseudo-elements
* Background gradients
* CSS animations
* 2D and 3D transformations
* Vendor prefixes

## Requirements

* All files are interpreted on Chrome 78.x
* All files must end with a new line
* CSS files must start with a comment describing the task
* Code must be W3C compliant
* Images are stored in the `images` directory

## Project

The project consists of styling the Techium homepage using advanced CSS techniques.
